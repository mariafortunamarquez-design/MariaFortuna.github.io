# María Fortuna — Tarjeta digital

Tarjeta de presentación personal desarrollada con HTML, CSS y JavaScript.

Reúne mis perfiles profesionales y mis datos de contacto en una página accesible desde el QR de mi tarjeta física.

## Ver la web

[Visitar mi tarjeta digital] (https://mariafortunamarquez-design.github.io/MariaFortuna.github.io/)

## Funcionalidades

- Diseño adaptable a dispositivos móviles y escritorio.
- Selector de tema claro y oscuro.
- Preferencia de tema guardada mediante localStorage.
- Fondo animado de estrellas y símbolos mediante Canvas.
- Enlaces a LinkedIn y GitHub.
- Sección de contacto desplegable.
- Botones para copiar el correo electrónico y el teléfono.

El proyecto utiliza HTML, CSS y JavaScript sin frameworks ni dependencias externas.
